# Tetris - Classic Block Puzzle Game
## Repository
<https://github.com/shoutingwen-byte/ANGM2305-Fall-2026-W1-Tetris-Game>
## Description
I will create a classic Tetris game using Python and Pygame. Players will control falling blocks, rotate and move them to complete rows, earn points. This project combines programming and digital art by creating an interactive game with colorful shapes, animations, and a user friendly interface.
## Features
- **Block Movement**
  - Allow players to move falling blocks left and right using keyboard controls.
- **Block Rotation**
  - Allow players to rotate blocks to fit different spaces.
- **Collision Detection**
  - Detect collisions between blocks, the game board, and the boundaries.
- **Line Clearing**
  - Detect and remove completed rows when the blocks form a full line.
- **Score System**
  - Award points based on the number of completed rows.
- **Next Block Preview**
  - Display the next block so players can plan their moves.
- **Increasing Difficulty**
  - Gradually increase the falling speed as the player's score increases.
- **Game Over and Restart**
  - Display a game-over screen when the board is full and allow players to restart the game.
## Challenges
- Learning how to organize the game loop and manage game states in Pygame.
- Implementing collision detection and block rotation correctly.
- Managing the game grid and removing completed rows.
- Understanding how to control falling speed and update the score.
## Outcomes
### Ideal Outcome:
- Create a fully playable Tetris game with all planned features, including block movement, rotation, collision detection, line clearing, scoring, and next block preview.

### Minimal Viable Outcome:
- Create a playable Tetris game where players can move and rotate falling blocks.
